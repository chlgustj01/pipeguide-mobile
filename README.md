# PipeGuide AI 배관 체험 (모바일)

휴대폰으로 QR을 찍으면 바로 열리는 PipeGuide 체험판입니다.
장비 두 개와 구경을 고르고 말로 요청하면, PipeGuide 엔진이 선박 기관실 3D 안에서 장애물을 피해 새 배관 경로를 찾아 그립니다.

**체험 주소:** https://chlgustj01.github.io/pipeguide-mobile/

![QR](qr.png)

## 체험 흐름
1. 시작 장비 · 목적 장비 · 구경 고르기 → 요청 문장 자동 작성 (직접 고쳐도 됨)
   예: “빌지 탱크에서 소화펌프 1까지 100A로 연결”
2. **실행** → 규칙 해석 → 장비 확인 → A* 경로 탐색 → 간섭 · 이격 검사 → 3D 성장 애니메이션
3. 결과: 후보 · 길이 · 엘보 · 간섭 · 최소 이격(기준 25 mm) → **등록** (예: 803-901N, 변경 이력 NEW)
4. 등록한 배관 고쳐 보기 (번호 없이 말해도 방금 만든 배관에 적용)
   - “300A로 바꿔줘” → 구경 변경 · 간섭 · 이격 재검사 (RESIZE)
   - “다른 길로” → 지금 경로와 다른 후보 → 적용 (REROUTE)
   - “되돌려줘” → 바로 앞 작업 취소 (UNDO)
   - 기존 배관은 번호를 함께: “733-443를 50A로 바꿔줘”

홈 화면에 추가하면 앱처럼 주소창 없이 열립니다 (Android Chrome: 메뉴 → 홈 화면에 추가 / iPhone Safari: 공유 → 홈 화면에 추가).

## 안내
- 문장은 **규칙 해석기**로 읽습니다. LLM은 연결하지 않았습니다.
- 장비 위치는 팀이 가정한 배치이며 실제 선박 좌표가 아닙니다. 이격 기준 25 mm는 팀 설정값입니다.
- 모든 계산은 관람객의 휴대폰 브라우저 안에서 일어나며, 서버로 보내는 데이터는 없습니다.
- AI Hub P&ID 원본 도면 그림은 포함하지 않았습니다 (팀 내부 시연용). 3D 생성에는 도면에서 읽어 둔 글자 정보만 사용합니다.
